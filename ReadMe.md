# Browser Image Editor

A lightweight image editing app that runs in the browser. Choose an image, adjust its appearance with live filters or preset looks, reset the edits, and download the result as a PNG. Image editing and rendering happen in the browser using the HTML canvas.

## Features

- Upload images from your device
- Adjust brightness, contrast, saturation, hue, blur, grayscale, sepia, opacity, and invert
- Apply presets including Vintage, Noir, Cool, Warm, Dramatic, Cyberpunk, Golden Hour, Fade, and Matrix
- Reset filters and download the edited image

## Technologies

- HTML for the page structure
- SCSS for styles and theme variables (compiled CSS is in `css/`)
- Vanilla JavaScript for controls, presets, and image processing
- HTML Canvas 2D API and CSS canvas filters for rendering
- Remix Icon via CDN for interface icons

## Run locally

Open `index.html` in a modern browser. No build step or package installation is currently required.
